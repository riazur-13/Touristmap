# New attraction candidates

Research for expanding the map from 28 to about 70 attractions across Chattogram Division. **Research only:** nothing in the app has changed. Produced on branch `feat/more-attractions`, 2026-09-30.

## How to read this

- **Status:** ✅ looks solid · ⚠️ doubtful, see the note · ❌ recommend dropping.
- **Coordinates:** an OpenStreetMap feature is preferred when it's a specific place (a temple, waterfall, beach and so on). Otherwise the Wikidata coordinate is used. When both exist, the table shows how far apart they are. Every chosen point was reverse-geocoded with OSM to confirm the district, and checked against the existing 28 for duplicates (anything within 3 km is flagged).
- **Photos:** only CC0, CC BY, CC BY-SA or public-domain files count. The license comes from each file's Commons metadata, not from a guess. The photo's source is shown in brackets, most reliable first:
  - *item image*: the photo Wikidata itself uses for the place;
  - *Commons category*: a file filed under the place's own category;
  - *text search*: a Commons keyword match, which must be checked by eye.
- **Using a photo:** CC BY and CC BY-SA require crediting the author and license. CC BY-SA also requires sharing any edited version under the same license. The app has no credits yet, so adding a photo credit line is part of the implementation.

## Method and caveats

- **Sources:** Wikidata (SPARQL discovery plus `wbsearchentities`), OpenStreetMap Nominatim (search and reverse geocoding, at most 1 request per second), and the Wikimedia Commons API (`imageinfo` license metadata). Each ⚠️ note says what to check.
- **Search matches can be wrong.** A Wikidata or Commons *search* match is the weakest evidence and is always flagged. Items I already knew from the discovery query are used directly.
- **"Coordinates: none found"** means neither OSM nor Wikidata has the place. It would need a manual point, or it should be dropped.
- **Nothing here is final:** categories are suggestions, and descriptions, fees and opening hours aren't researched yet. That's the next phase, after your review.
